# Как внести вклад

Спасибо, что хочешь улучшить роадмап. Правки в текст, новые задачи, схемы и исправления опечаток одинаково полезны.

## Структура репозитория

Материалы разбиты на пронумерованные модули верхнего уровня. У каждого модуля свой `README.md`-индекс, плоские уроки `NN-topic.md` и папка `assets/` со схемами.

```
01-fundamentals/   02-java-core/   03-tools/        04-persistence/
05-spring/         06-design/      07-reliability/  08-infrastructure/
09-interview/      10-leadership/
```

## Правила оформления уроков

- Файл урока — `NN-topic.md` в kebab-case, где `NN` задаёт порядок внутри модуля
- Вверху: заголовок `# Название`, три бейджа (модуль · уровень · тема), одно-два предложения вступления
- Схемы — свои SVG в `assets/` этого модуля, вставка через `<p align="center"><img src="assets/...svg" width="860"></p>`
- Внизу — навигация: `[← предыдущий] · [Оглавление](README.md) · [следующий →]`
- Человеческий текст: без ИИ-нарратива, без длинных прочерков (`—`, `--`), без точек в конце пунктов списка
- Код в блоках с указанием языка (` ```java `)

## Схемы

SVG рисуем в тёмной палитре роадмапа. Перед вставкой проверяй, что файл валиден и нормально рендерится, а не только открывается в редакторе.

## Процесс

1. Форкни репозиторий и заведи ветку `docs/<что-меняешь>`
2. Сделай правки, проверь, что относительные ссылки не побились
3. Открой pull request с коротким описанием, что и зачем

Вопросы и предложения — через issue.
